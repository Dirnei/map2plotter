map2plotter

Load a location, customize the poster on a live preview, then export it.

Location

4000–6000 m: small/dense cities · 8000–12000 m: downtown · 15000–20000 m: full metro

Poster size

Any size. The SVG is drawn in real millimetres, stroke-only, one layer per pen colour.

Map data

    Pens

    Pick a pen colour per element. Elements with the same colour share a pen and a layer in the SVG. Colour changes show at once, without re-rendering.

    Labels

    Text uses a single-line pen font. Accents are simplified, and scripts it cannot draw (e.g. CJK) are skipped.

    Pen & fills
    Export
